# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[Semantic Versioning](https://semver.org/lang/ru/).

## 0.2.1 — 2026-10-27

### Исправлено

- `--update` и установщик принимают имена релизных ассетов как с префиксом
  `v`, так и без него.
- Release workflow теперь всегда публикует ассеты с `v` в имени, чтобы
  обновление и установка работали с любой версией.

## 0.2.0 — 2026-10-27

### Добавлено

- Автоматическая проверка терминала: классическая консоль Windows (conhost)
  переключается на ASCII-иконки, чтобы символы не превращались в квадратики.
- Подробная диагностика терминала в `--check`: программа, шрифт, кодовая
  страница, elevated-режим и поддержка Unicode.
- Таймер сна.
- Сортировка библиотеки.
- Избранное, счётчики прослушиваний и «Recently played».
- Импорт и экспорт плейлистов M3U/M3U8.
- Discord Rich Presence с публичным Application ID по умолчанию; включается
  сразу, отключается через `data\discord.json`.
- Универсальный установщик для текущего пользователя: без администратора,
  с выбором папки, зависимостями, ярлыками и uninstaller.
- Автоматические сборки и релизы через GitHub Actions.
- Linux-сборка в CI (`CGO_ENABLED=1`, ALSA) и Linux-архив
  `linux-amd64.tar.gz` в релизах.
- Обновление `--update` с проверкой SHA256 и перезапуском.
- Uninstaller и запись в «Программах и компонентах» для текущего пользователя.
- Журнал работы в `data\logs` и восстановление после паники.
- Защита от одновременного запуска двух копий плеера.
- Атомарная запись JSON с резервной копией `.bak`.
- Повреждённый `playlists.json` сохраняется как `.corrupt-*`, плеер запускается
  с пустым списком вместо падения.

### Исправлено

- Запуск от администратора больше не оставляет пользователя с квадратиками
  вместо иконок и чужим шрифтом без предупреждения.
- Windows Terminal, выбранный терминалом по умолчанию, определяется через
  pseudoconsole — ASCII-режим больше не включается ложно при запуске из
  Проводника.

## 0.1.0 — 2026-10-26

Первый публичный релиз.

### Добавлено

- Офлайн-воспроизведение MP3, FLAC и WAV без CGO на Windows.
- Скачивание отдельных треков Spotify, SoundCloud, YouTube и прямых ссылок
  через `yt-dlp` и `ffmpeg`.
- Библиотека, поиск, плейлисты, drag-and-drop и мультивыделение.
- Обложки, семь тем, FFT-визуализатор и полноэкранный режим обложки.
- Кроссфейд 5 секунд, shuffle, repeat all/one, восстановление сессии.
- Управление мышью.
- Опциональный Discord Rich Presence.
- Установщик последнего релиза с проверкой SHA256 и ярлыками.
