# xngxltuiplayer 0.5.0

Downloads 2.0 без Spotify: YouTube-плейлисты, SoundCloud-сеты, предпросмотр и
пакетная очередь с несколькими воркерами.

## Что нового

### Плейлисты и сеты

- Вставьте ссылку `youtube.com/playlist?list=...` или
  `soundcloud.com/user/sets/...` в окно `a`.
- Список треков читается через `yt-dlp -J --flat-playlist`; аудио не качается,
  пока вы не подтвердите загрузку.
- YouTube Music и `embed/videoseries` ссылки тоже работают.
- Удалённые, приватные и живые записи пропускаются.

### Предпросмотр

Перед постановкой в очередь видно:

- название плейлиста или сета;
- автора или канал;
- число треков и суммарную длительность;
- сколько записей пропущено;
- первые восемь треков списком.

`Enter` — скачать всё, `Esc` — отмена. Лимит — 500 треков на пакет.

### Очередь

- Несколько загрузок одновременно: `-download-workers 1..6`, по умолчанию 2.
- Пакет отображается в окне загрузок группой с track number и прогрессом.
- Дубликаты внутри пакета пропускаются.
- `r` — повторить выбранный failed-трек, `R` — все failed.
- `c`/`x` — отменить выбранный, `X` — все активные.
- После завершения группы показывается один итоговый тост, а не по одному на
  каждый трек.

### Теги

- Track number пишется в `TRCK`, альбом — в `TALB`.
- Обложка берётся из плейлиста или первого трека.
- Файлы по-прежнему сохраняются в общий `music/` с именем
  `Исполнитель - Название.mp3`.

## Чего нет

- Spotify-плейлистов и альбомов: для них нужен Spotify Web API и OAuth, это
  отдельный этап. Одиночные Spotify-треки работают как раньше.
- Паузы и продолжения загрузок.
- Автоматического создания плейлиста в приложении после пакета.
- Папок `Исполнитель/Альбом` в библиотеке.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

Затем:

1. `a` → ссылка на YouTube-плейлист → `Enter`.
2. Проверьте предпросмотр и нажмите `Enter`.
3. `d` — прогресс группы, `r`/`R` на failed-треках.
4. Повторите для SoundCloud-сета.

Для ограниченных источников по-прежнему можно положить `data/cookies.txt`.
