# xngxltuiplayer 0.2.1

Патч-релиз к 0.2.0. Исправляет поломку интерфейса при длинных ошибках
загрузок и делает работу с релизными ассетами устойчивее.

## Исправлено

- Окно загрузок больше не разъезжается при длинных ошибках `yt-dlp`.
- Управляющие символы, ANSI-последовательности, табы, переводы строк и
  невалидный UTF-8 очищаются до вывода в терминал.
- Добавлена финальная защита кадра: каждая строка обрезается до ширины
  терминала и не может вызвать перенос/сдвиг всего интерфейса.
- Очистка применяется к ошибкам, toast, названиям треков и плейлистов,
  путям, stage, warning и другим динамическим данным.
- `--update` и установщик принимают имена ассетов как с `v`, так и без него.
- Release workflow теперь всегда публикует ассеты с `v` в имени.

## Установка

### Windows

1. Скачайте `xngxltuiplayer-v0.2.1-windows-amd64.zip` и распакуйте.
2. Запустите `install_xngxltuiplayer.bat`.
3. Enter — установка в `%LOCALAPPDATA%\Programs\xngxltuiplayer`, или
   укажите свою папку.

Можно запускать портативно без установки. `music\` и `data\` при обновлении
сохраняются.

### Linux

```bash
tar -xzf xngxltuiplayer-v0.2.1-linux-amd64.tar.gz
./xngxltuiplayer --check
./xngxltuiplayer
```

Нужны ALSA/PulseAudio/PipeWire и терминал с Unicode, truecolor и мышью.
Для скачивания — `yt-dlp` и `ffmpeg`.

`1563968728352161852`. Отключается через `data\discord.json`:

```json
{
  "enabled": false
}
```

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

SHA256 для архивов лежит рядом с ассетами в релизе.

## Ограничения

- Windows-exe не подписан, возможен SmartScreen.
- Linux-архив собран для amd64.
- `--update` и uninstaller — только Windows.
- Discord Rich Presence проверен на Windows; на Linux IPC реализован, но
  отдельно не тестировался.
- Скачивайте только контент, на который у вас есть права.
