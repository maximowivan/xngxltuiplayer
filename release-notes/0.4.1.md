# xngxltuiplayer 0.4.1

Обновление про удобство: обложки теперь можно менять прямо в редакторе тегов,
тем стало 22, а Windows-сборка сама проверяет новые релизы и умеет обновляться
из плеера.

## Обложки в редакторе тегов

- `e` открывает редактор, как раньше.
- Новая строка `Cover` показывает состояние обложки.
- `c` — выбрать файл по пути или перетащить картинку в терминал.
- `x` — удалить обложку.
- Поддерживаются JPEG, PNG, WebP и GIF; картинка нормализуется в JPEG до 900 px
  и обрезается до квадрата.
- MP3: заменяется front cover `APIC`, остальные картинки и теги сохраняются.
- FLAC: заменяется/добавляется `PICTURE`, остальные блоки не трогаются.
- Запись атомарная; кэш обложек обновляется. Если редактируется играющий трек,
  воспроизведение останавливается перед заменой файла.

## 22 темы

Добавлены Catppuccin Macchiato, Frappe и Latte, Tokyo Night Storm, Gruvbox
Light, Solarized Dark и Light, One Dark, Monokai, Kanagawa, Everforest,
Nightfox, Rose Pine Dawn, GitHub Dark и Light.

- `t`/`T` листают темы вперёд и назад.
- `Ctrl+T` открывает список с живым превью: стрелки — предпросмотр, `Enter` —
  применить, `Esc` — вернуть исходную тему.
- Для светлых тем подобран контраст текста, выделения, toast-уведомлений и
  placeholder-обложки.
- Выбор сохраняется в `data\session.json`.

## Автообновление на Windows

- При каждом запуске плеер в фоне запрашивает последний релиз на GitHub.
- Если версия новее, появляется окно с текущей и новой версией.
- `Enter` — обновить: скачивание с прогрессом в МБ, проверка SHA256,
  распаковка и перезапуск.
- `Esc` — отложить; `U` откроет предложение снова.
- Ошибки сети и проверки не мешают работе: причина пишется в `data\logs`.
- `music\`, `data\`, `terminal\` и настройки сохраняются.
- `--update` в консоли тоже показывает прогресс.

**Важно:** в 0.4.0 автопроверки ещё нет. Первый переход на 0.4.1 нужно сделать
вручную — через `--update` или установщик. Дальше 0.4.1 сможет предлагать
следующие версии сама.

## Установщик

- Скачивание zip релиза и Windows Terminal показывает прогресс в МБ, проценте
  и скорости.
- `yt-dlp` и `ffmpeg` по-прежнему ставятся через winget, если их нет; winget
  показывает прогресс зависимостей сам, установщик добавляет понятные этапы.
- Portable Windows Terminal остаётся опциональным.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

В редакторе тегов проверьте `c`/`x` на MP3 и FLAC. На Windows после запуска
должна появиться проверка обновлений; если сеть недоступна, плеер просто
работает дальше.

## Ограничения

- Обложки и теги — только MP3 и FLAC; WAV/M4A/OGG не редактируются.
- Автообновление только для Windows; на Linux обновляйтесь новым архивом.
- Windows media keys работают без системного оверлея SMTC.
- Linux MPRIS реализован, но на живом GNOME/KDE ещё требует проверки.
- `data/trash/` после слияния дублей чистится вручную.
- Скачивайте только контент, на который у вас есть права.
