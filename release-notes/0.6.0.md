# xngxltuiplayer 0.6.0

Audio 2.0: 10-полосный эквалайзер и tape-style скорость без перезапуска трека.

## Эквалайзер

- 10 полос: **31, 62, 125, 250, 500, 1k, 2k, 4k, 8k, 16k Гц**.
- Диапазон **±12 дБ**, preamp **±12 дБ**.
- Пресеты:
  - **Flat** — всё в нуле;
  - **Bass** — низкие частоты;
  - **Vocal** — середина;
  - **Electronic** — широкий подъём.
- `Q` открывает окно. `←/→` выбирают полосу, `↑/↓` меняют на 1 дБ,
  `0` сбрасывает полосу, `1–4` включают пресет, `-/+` меняют preamp,
  `Tab` листает пресеты.
- Изменения слышны сразу: фильтры применяются к текущему потоку, трек не
  перезапускается.
- Flat полностью обходит фильтр и не трогает сэмплы.
- На узких терминалах полосы раскладываются в два ряда по пять.
- Спектроанализатор стоит после эквалайзера и показывает реальную АЧХ.

## Скорость

- Диапазон **0.5–2.0x**, шаг **0.05**.
- `[` — медленнее, `]` — быстрее, `\` — сброс на `1.00x`.
- Это **tape-style**: вместе со скоростью меняется тон. Pitch-preserving
  time-stretch не поддерживается.
- Скорость применяется к текущему треку и ко всем следующим.
- Позиция, длительность и seek остаются в времени трека, поэтому прогресс-бар
  движется быстрее или медленнее вместе с воспроизведением.
- Кроссфейд остаётся 5 секунд по настенным часам и корректно работает на
  `0.5x` и `2.0x`.
- Бейдж `1.25x` в плеере показывает нестандартную скорость.

## Сохранение

В `data/session.json` добавлены:

```json
{
  "speed": 1.25,
  "eq": [6, 5, 3, 1, 0, 0, 0, 0, 0, 0],
  "eq_preamp": -3
}
```

Старые сессии без этих полей открываются с Flat и `1.00x`.

## Что не вошло

- Pitch-preserving time-stretch.
- ReplayGain и нормализация громкости.
- Gapless-воспроизведение.
- Выбор аудиоустройства.
- Индивидуальные EQ/скорость для разных треков.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

Затем:

1. Запустите трек и нажмите `]` несколько раз — появится бейдж скорости.
2. Нажмите `Q`, выберите `2` (Bass), подвигайте полосы стрелками.
3. `\` вернёт скорость `1.00x`, `1` в окне EQ — Flat.
4. Перезапустите плеер: скорость и эквалайзер должны восстановиться.

Проверьте на `-rate 44100`, если используете старый ЦАП или Bluetooth-гарнитуру.
