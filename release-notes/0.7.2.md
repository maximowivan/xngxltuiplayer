# xngxltuiplayer 0.7.2

Небольшой фикс выбора нескольких результатов поиска.

## Исправлено

- Одиночное нажатие `Ctrl` больше не закрывает список результатов и не
  возвращает к полю ввода. Пустые служебные key-события игнорируются.
- Добавлена клавиша `x` для выбора результата. В некоторых терминалах
  `Ctrl+Space` перехватывается системой (IME/Windows Terminal) и не доходит
  до плеера.
- Подсказка в окне поиска показывает `Ctrl+Space / x`.

## Как выбрать несколько

1. `a` → введите запрос → `Enter`.
2. `x` или `Ctrl+Space` на нужных результатах.
3. `Enter` — скачать выбранные.

`Ctrl+A` выбирает все результаты, `Ctrl+Click` работает при включённой мыши.
Превью — `Space`.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
```

Проверьте: нажатие одного `Ctrl` не должно закрывать список; `x` должен
ставить и снимать галочку.
