# xngxltuiplayer 0.3.0

Релиз про совместимость с терминалами. Плеер больше не требует Windows
Terminal: без него включается аккуратный режим совместимости, а полный вид
остаётся в Windows Terminal и современных терминалах Linux.

## Режимы интерфейса

| Режим | Где | Что видно |
| --- | --- | --- |
| `full` | Windows Terminal, VS Code, WezTerm, kitty, современный Linux-терминал | Unicode, truecolor, полублочная обложка |
| `compat` | conhost с TrueType-шрифтом | Unicode-рамки, ASCII-иконки, бары, курсоры и FFT |
| `ascii` | растровый conhost, `TERM=linux`, `dumb`, не-UTF-8 локаль | только ASCII, ASCII-обложка |

Режим выбирается автоматически. Принудительно:

```powershell
.\xngxltuiplayer.exe -ui auto|full|compat|ascii
.\xngxltuiplayer.exe -ascii
.\xngxltuiplayer.exe -color auto|truecolor|256|16|none
```

`-ascii` теперь переключает **весь** интерфейс, а не только подписи иконок.
`-icons auto|unicode|ascii` остался для управления только иконками.

## Исправлено

- Полоса громкости больше не использует `▮/▯`: в Windows Terminal они
  отображались пустыми квадратиками. Теперь `█/░`.
- В `compat/ascii` убраны хрупкие глифы курсоров, прогресса, спиннера и FFT.
- В `16/none` больше не отправляются 24-bit цвета, которые не понимает
  терминал.
- При выключенном VT/legacy console плеер пишет понятную ошибку вместо
  сломанного экрана.
- На Linux TTY, `dumb` и при не-UTF-8 локали включается ASCII-режим.
- `--check` показывает TTY, VT, шрифт, цветовой профиль, режим глифов, мышь и
  рекомендацию.

## Windows Terminal теперь опционален

Установщик проверяет установленный Windows Terminal через пакет, а не только
по `wt.exe` (иначе можно было создать ярлык на заглушку Store). Если WT нет,
он предлагает, но не требует поставить портативный Windows Terminal:

- официальный ZIP Microsoft, ~12 МБ;
- Windows 10 2004+;
- без администратора;
- SHA256 и подпись Microsoft проверяются;
- распаковывается в `terminal\` рядом с плеером;
- ярлык ведёт в него, `music\` и `data\` не затрагиваются.

Флаги установщика: `-WithTerminal`, `-NoTerminal`, `-PortableTerminal`,
`-TerminalZip <path>`. Uninstaller удаляет портативный терминал.

Без Windows Terminal плеер полностью работоспособен в `compat`/`ascii`;
полный Unicode-вид зависит от шрифта, а conhost не делает fallback шрифта.

## Установка

### Windows

1. Скачайте `xngxltuiplayer-v0.3.0-windows-amd64.zip` и распакуйте.
2. Запустите `install_xngxltuiplayer.bat`.
3. Enter — установка в `%LOCALAPPDATA%\Programs\xngxltuiplayer`, или
   укажите свою папку.
4. Если Windows Terminal не найден, ответьте `y`, чтобы поставить
   портативный WT, или `N`, чтобы остаться в режиме совместимости.

`music\` и `data\` при обновлении сохраняются.

### Linux

```bash
tar -xzf xngxltuiplayer-v0.3.0-linux-amd64.tar.gz
./xngxltuiplayer --check
./xngxltuiplayer
```

Нужны ALSA/PulseAudio/PipeWire и UTF-8-терминал. Windows Terminal для Linux
не нужен. На голой TTY автоматически включается ASCII-режим.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

В `--check` смотрите раздел `Terminal`: `tty`, `vt`, `font`, `color`,
`glyphs`, `mouse` и `hint`.

## Ограничения

- Windows-exe не подписан, возможен SmartScreen.
- Linux-архив собран для amd64.
- В `compat/ascii` обложка и FFT упрощены; темы в 16 цветах приближены.
- Портативный Windows Terminal требует Windows 10 2004+.
- `--update` обновляет только плеер; для опционального WT запустите установщик
  из релиза.
- Discord Rich Presence проверен на Windows; на Linux IPC реализован, но
  отдельно не тестировался.
- Скачивайте только контент, на который у вас есть права.
