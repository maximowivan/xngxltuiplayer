# xngxltuiplayer 0.4.0

Релиз про работу с локальной библиотекой: папка `music/` обновляется сама,
дубликаты можно безопасно сливать, теги — редактировать из плеера, а
медиа-клавиши управляют воспроизведением.

## Автообновление библиотеки

- Новые, удалённые и переименованные файлы в `music/` подхватываются
  автоматически, без `u`.
- Изменения склеиваются с задержкой ~0,5 с, чтобы копирование не вызывало
  сотни сканирований.
- Для сетевых папок, где нет нативных уведомлений, работает опрос раз в
  30 секунд.
- Текущий трек и очередь не сбрасываются; если файл играющего трека удалён,
  плеер аккуратно останавливается.
- Флаг `-watch auto|on|off`.

## Дубликаты и слияние

- Клавиша `M`.
- Группы по нормализованным исполнителю и названию, длительность ±2 секунды;
  для точных копий дополнительно считается SHA-256.
- В группе видно путь, размер и примерный битрейт. Файл для сохранения
  выбирается вручную; по умолчанию предлагается лучший по качеству.
- При слиянии:
  - ссылки в плейлистах заменяются на оставшийся файл;
  - favourite, число прослушиваний и последняя дата объединяются;
  - очередь и текущий трек обновляются;
  - лишние файлы **перемещаются в `data/trash/`**, а не удаляются сразу.
- `data/trash/` можно очистить вручную, когда убедитесь, что всё в порядке.

## Редактор тегов

- Клавиша `e` для выбранного трека.
- Поля: title, artist, album, year, track number.
- Форматы: MP3 (ID3v2.4) и FLAC (Vorbis comments).
- Запись атомарная: временная копия, изменение, замена файла. Обложка и
  неизвестные теги сохраняются.
- Если редактируется играющий трек, воспроизведение останавливается перед
  заменой файла.
- Обложка в этом релизе не редактируется; WAV/M4A/OGG не поддерживаются.

## Медиа-клавиши

- Windows: глобальные Play/Pause, Next, Previous, Stop через `RegisterHotKey`.
  Системного оверлея Windows (SMTC) в этом релизе нет.
- Linux: MPRIS2. Медиа-клавиши рабочего стола и виджет «сейчас играет» в
  GNOME/KDE получают название, исполнителя, альбом, статус, позицию и громкость.
- Если Windows не даёт зарегистрировать клавиши (их занял другой плеер),
  плеер продолжает работать; причина пишется в лог.
- `--check` показывает доступный backend.

## Установка

### Windows

1. Скачайте `xngxltuiplayer-v0.4.0-windows-amd64.zip` и распакуйте.
2. Запустите `install_xngxltuiplayer.bat`.
3. Enter — установка в `%LOCALAPPDATA%\Programs\xngxltuiplayer`.
4. Если Windows Terminal не найден, можно поставить портативный WT, как в
   0.3.0. Без него работает режим совместимости.

`--update` обновляет exe; для опционального WT запустите установщик из релиза.

### Linux

```bash
tar -xzf xngxltuiplayer-v0.4.0-linux-amd64.tar.gz
./xngxltuiplayer --check
./xngxltuiplayer
```

Нужны ALSA/PulseAudio/PipeWire, UTF-8-терминал и D-Bus для MPRIS.
Windows Terminal не нужен.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

В разделе `Terminal` смотрите `glyphs`, `color`, `watch` и `media keys`.

## Ограничения

- Windows-exe не подписан, возможен SmartScreen.
- Linux-архив собран для amd64.
- Редактор тегов: только MP3/FLAC и без обложки.
- Дубликаты: окончательное решение всегда за пользователем; `data/trash/`
  чистится вручную.
- Windows media keys — без SMTC-оверлея.
- Linux MPRIS реализован, но на живом desktop ещё требует проверки.
- Discord Rich Presence проверен на Windows; на Linux IPC реализован, но
  отдельно не тестировался.
- Скачивайте только контент, на который у вас есть права.
