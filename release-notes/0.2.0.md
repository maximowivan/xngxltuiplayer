# xngxltuiplayer 0.2.0

Второй публичный релиз офлайн-плеера с терминальным интерфейсом.

## Что нового

### Надёжность

- Атомарная запись `library.json`, `playlists.json`, `session.json`,
  `stats.json` и `discord.json` с резервной копией `.bak`.
- Восстановление из `.bak` при повреждении JSON.
- Повреждённый `playlists.json` сохраняется как `.corrupt-*`, плеер
  запускается с пустым списком вместо падения.
- Журнал работы в `data\logs\xngxltuiplayer.log`, перехват паники.
- Защита от двух одновременно запущенных копий на одной папке `data`.

### Терминал

- Автоматическое определение Windows Terminal, VS Code, WezTerm, Alacritty,
  kitty и классической консоли Windows.
- В conhost автоматически включаются ASCII-иконки, чтобы `⇄`, `↻` и `▣`
  не превращались в квадратики.
- Windows Terminal, выбранный терминалом по умолчанию, определяется через
  `PseudoConsoleWindow` — запуск из Проводника больше не сбивает режим.
- Флаг `-icons auto|unicode|ascii`.
- Диагностика терминала в `--check`: программа, шрифт, кодовая страница,
  elevated-режим и Unicode.

### Плеер

- Таймер сна: `z`, 15/30/45/60 минут.
- Сортировка: `o`, исполнитель/название/альбом/год/недавние.
- Избранное: `f`, разделы **Favorites** и **Recent**, счётчики прослушиваний.
- Импорт и экспорт M3U/M3U8: `I` и `E`.
- Discord Rich Presence теперь включён по умолчанию с публичным Application ID
  и работает сразу. Отключается через `data\discord.json`.
- `--update` скачивает последний Windows-релиз, проверяет SHA256, заменяет exe
  и перезапускает плеер. Музыка и `data\` не затрагиваются.

### Установка и Linux

- Новый установщик для текущего пользователя: без администратора, с выбором
  папки, зависимостями, ярлыками, uninstaller и записью в «Программах и
  компонентах».
- По умолчанию установка в `%LOCALAPPDATA%\Programs\xngxltuiplayer`.
  При обновлении `music\` и `data\` сохраняются.
- Linux-сборка в CI и релизный архив `linux-amd64.tar.gz`.
- На Linux для сборки нужны CGO и ALSA (`libasound2-dev`); готовый архив
  собирается в CI.

## Установка

### Windows

1. Скачайте `xngxltuiplayer-v0.2.0-windows-amd64.zip` и распакуйте.
2. Запустите `install_xngxltuiplayer.bat`.
3. Нажмите Enter для установки в `%LOCALAPPDATA%\Programs\xngxltuiplayer`
   или укажите свою папку.
4. Установщик создаст ярлыки, uninstaller и запись в «Программах и
   компонентах». Администратор не нужен.

Можно и портативно: запускать `xngxltuiplayer.exe` прямо из распакованной
папки, без установки.

### Linux

```bash
tar -xzf xngxltuiplayer-v0.2.0-linux-amd64.tar.gz
./xngxltuiplayer --check
./xngxltuiplayer
```

Нужны ALSA/PulseAudio/PipeWire и терминал с Unicode, truecolor и мышью.
Для скачивания — `yt-dlp` и `ffmpeg`.

## Discord

Rich Presence включён по умолчанию. Application ID `1563968728352161852`
публичный и не является секретом. Чтобы отключить:

```json
{
  "enabled": false
}
```

в `data\discord.json`. Свой Application ID можно задать флагом
`-discord <id>`.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
.\xngxltuiplayer.exe --check
```

SHA256 для архивов лежит рядом с ассетами в релизе.

## Ограничения

- Windows-exe не подписан, возможен SmartScreen.
- Linux-архив собран для amd64; для ARM64 собирайте из исходников.
- `--update` и uninstaller — только Windows.
- Поддерживаются отдельные треки Spotify/SoundCloud; плейлисты и альбомы
  отклоняются.
- Discord Rich Presence проверен на Windows; на Linux IPC реализован, но
  отдельно не тестировался.
- Скачивайте только контент, на который у вас есть права.
