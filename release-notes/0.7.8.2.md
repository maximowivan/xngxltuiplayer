# xngxltuiplayer 0.7.8.2

Небольшая правка ряда управления в большом режиме.

## Что изменилось

- `shuffle` и `repeat` перенесены в один ряд с транспортом:
  `⇄ ◀◀ ⏯ ▶▶ ↻`.
- Ряд центрирован по горизонтали, как на основном экране.
- Отдельные иконки слева под прогрессом больше не показываются.
- Клики по `shuffle`, `repeat`, предыдущему/следующему треку и паузе работают
  как раньше.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
```

1. Запустите трек и нажмите `c`.
2. В широком окне проверьте ряд `⇄ ◀◀ ⏯ ▶▶ ↻` под прогрессом.
3. Нажмите `⇄` — должен включиться shuffle.
4. Нажмите `↻` — должен смениться режим повтора.
5. Проверьте паузу и переключение треков.
6. `c` или `Esc` — закрыть большой режим.

## Ограничения

- В conhost мышь отключена самим терминалом; клики проверяются в Windows
  Terminal и других терминалах с mouse mode.
- Обложка по-прежнему рисуется полублоками, без sixel/Kitty graphics.
