# xngxltuiplayer 0.7.6

Большой режим обложки теперь собран в сетку 2×2.

## Что нового

- В широком окне большой режим показывает четыре панели:
  - обложка;
  - `UP NEXT`;
  - `Player`;
  - визуализатор.
- Верхний ряд занимает свободную высоту, нижний остаётся компактным.
- При сужении окна или недостатке высоты включается компактный вид с обложкой
  и `Player`; панели не сжимаются до нечитаемого состояния.
- Клик по строке `UP NEXT` запускает выбранный трек и не закрывает большой
  режим.
- В `UP NEXT` показываются длительности и подсказка `click to play`, если
  терминал поддерживает мышь.
- Визуализатор считает полосы по ширине своей панели.
- Клики по обложке, прогрессу, паузе, предыдущему/следующему треку, shuffle и
  repeat работают и после изменения размера окна.

## Проверка

```powershell
.\xngxltuiplayer.exe --version
```

1. Запустите трек и нажмите `c`.
2. В широком окне проверьте четыре панели: `COVER`, `UP NEXT`, `PLAYER`,
   `VISUALIZER`.
3. Нажмите `n` и убедитесь, что `UP NEXT` показывает реальный следующий трек.
4. Кликните по строке `UP NEXT` — должен запуститься именно этот трек.
5. Уменьшите окно по ширине и высоте — сетка должна смениться компактным видом,
   а затем вернуться при увеличении.
6. Проверьте клик по паузе и перемотку по прогрессу после нескольких ресайзов.
7. `c` или `Esc` — закрыть большой режим.

## Ограничения

- В conhost мышь отключена самим терминалом; клики по `UP NEXT` проверяются в
  Windows Terminal и других терминалах с mouse mode.
- Обложка по-прежнему рисуется полублоками, без sixel/Kitty graphics.
