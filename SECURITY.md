# Security

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Send a private message
to the repository owner or use GitHub's private vulnerability reporting.

Include:

- the affected version;
- steps to reproduce;
- what an attacker could do;
- any suggested fix.

The player stores music paths, playlists and session data locally. It does not
send telemetry. `yt-dlp` and `ffmpeg` are external tools installed separately
and are not covered by this project's security policy.
